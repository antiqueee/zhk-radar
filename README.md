# Мегаполис Интеледженс

Внутренний инструмент агентства: найти проблемные ЖК, открыть PDF-разбор,
при необходимости добавить переписку и уточнить предложение услуг.

**Работает локальная версия с интерфейсом. Полный автоматический мониторинг
из исходного ТЗ ещё не завершён.** Все исходные требования сохранены в [SPEC](docs/SPEC.md).

```sh
uv sync --frozen
uv run radar serve
```

Открыть **http://127.0.0.1:8765** или запустить `Запустить Мегаполис.command`.
Ключи добавляются через «Подключения» в шапке. Без ключей доступны материалы
агентства, импорт Excel/JSON, уточнения и PDF; отдельные демо-примеры вымышлены.

Реализовано:

- Простой интерфейс с логотипом агентства, поиском по списку и PDF в один клик.
- Сохранение ключей через сайт; модель заменяется через настройки, без правок кода.
- Поисковый пилот Yandex → модель OpenRouter → проверка схемы/цитат → карточки.
  Проверен на HTTP-подменах, не проверен с боевыми ключами. Использует поисковые фрагменты.
- Импорт пяти форматов Excel с происхождением каждой строки: локально 102 записи,
  из них 64 записи по объектам/смешанным сущностям в главном списке, включая повторы.
- SQLite для локальных решений, истории, доказательств и версий PDF.
- Импорт открытой переписки JSON, HMAC авторов, сводка за 30 дней, темы в PDF.
  Разметка тем/тональности берётся из выгрузки, не выполняется автоматически.
- Двухстраничные внутренние PDF с уточнениями, источниками, данными чатов
  и подбором из 12 черновых пакетов услуг агентства.
- Расчётное ядро R1–R7 и три оси; реальные исходные строки автоматически не оцениваются.
- Начальная схема PostgreSQL, Alembic, Docker Compose и CI для будущего серверного конвейера.
- Локальный backup SQLite и 58 офлайн-тестов; браузерный сценарий desktop/mobile.

Ещё не реализованы: проверка полных первоисточников и реестров, автоматический
читатель Telegram, модельная разметка чатов, недельное расписание, доставка в Telegram,
синхронизация Sheets и production-развёртывание. Заполнение всех ключей пока
не превращает эту версию в полностью автоматическую систему из ТЗ.

Проверки:

```sh
uv run pytest -q
uv run ruff check .
uv run ruff format --check .
node --check src/radar/web/static/app.js
uv run python scripts/check_ui.py # требует работающего локального сервера и Chrome
uv run radar backup
```

PDF проверен на всех 102 исходных записях. Боевые интеграции не запускались.
PostgreSQL локально не установлен: миграция проверялась генерацией SQL,
GitHub workflow подготовлен, но не запускался. Материалы, ключи и рабочие данные
не включены в Git. Шрифт DejaVu поставляется с лицензией, логотип предоставлен заказчиком.
