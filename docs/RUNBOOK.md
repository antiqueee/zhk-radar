# Локальная разработка

Боевой сервис ещё не развёрнут. Эта инструкция относится только к прототипу.

- Проверка ядра: `uv run radar demo`; тесты: `uv run pytest -q`.
- Проверка SQL без сервера: `uv run alembic upgrade head --sql`.
- Проверка тестовой базы: `docker compose ps`, затем `uv run alembic current`.
- Миграция: `uv run alembic upgrade head`; сверка схемы: `uv run alembic check`.
- Остановка тестовой базы без удаления данных: `docker compose stop db`.
- Если нет Docker, расчёты и офлайн-тесты продолжают работать.
- `.env`, сессии, ключи и реальные тексты чатов не коммитить.

Перед эксплуатацией нужны отдельные проверенные процедуры восстановления БД,
шифрованных бэкапов, мониторинга прогонов и ротации секретов. Пока они не реализованы.
