# Завершение рабочего MVP

Запрос 10.11.2026: закончить оставшуюся реализацию автономно. Основной интерфейс — сайт;
Telegram используется для чтения источников и доставки, а не дублирования всех экранов сайта.
Оригинальные ограничения «без UI» и «ровно две страницы» отменены пользователем.

Уже завершено: поиск и снимки источников, досье, подробные PDF, открытые чаты и модельная
разметка, недельное расписание, доставка ботом, сравнительный стенд, лимиты вызовов.

Оставшаяся реализация:
- [x] Стоп-лист, причины отказов, безопасная работа с кандидатами.
- [x] Реестровые снимки и привязка корпусов, сравнение дат и подключение расчётного ядра.
- [x] Семантическое ревью модели и операторская проверка с привязкой к версии данных.
- [x] Google Sheets: системные листы, идемпотентная синхронизация, отдельные заметки.
- [x] Серверный режим: вход, роли, защита секретов, Docker, healthcheck.
- [x] Автоматические резервные копии, история состояния, интеграция дополнений в расписание.
- [x] Итоговые автономные проверки, обновлённая инструкция и перечень внешних условий запуска.

Внешние условия, которые нельзя подтвердить тестовыми данными: реальные ключи, авторизация
Telegram, доступ к реестрам с целевого сервера, права таблицы, инфраструктура заказчика,
приёмка агентством и несколько недель реального использования. Их наличие не предполагается.

Проверки контейнерного запуска и реальных API отделены от выполненной реализации;
см. SERVER.md и LOCAL_MVP.md. Веб-хранилище намеренно остаётся SQLite в одном процессе.
