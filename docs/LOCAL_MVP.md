# Мегаполис Интеледженс: локальная версия

## Пользовательский сценарий

Откройте http://127.0.0.1:8765. Один экран: выбрать географию → найти объекты →
скачать PDF. В карточке можно добавить переписку и уточнения, затем обновить PDF.
«Подключения» в шапке сохраняют ключи прямо из браузера.

На этом компьютере уже загружены 102 исходные записи из пяти книг. 38 записей
относятся только к девелоперам; главный список показывает остальные 64 записи.
Исходные строки сохраняются отдельно: это не 64 уникальных подтверждённых ЖК.
В наборе «Демо-примеры» есть четыре вымышленных объекта; их можно безопасно менять.

## Запуск

Двойной щелчок по `Запустить Мегаполис.command` в корне проекта или:

```sh
uv sync --frozen
uv run radar serve
```

Открыть http://127.0.0.1:8765. Сервер слушает только loopback. Остановить: Ctrl+C
в его терминале. Это однопользовательское приложение на компьютере, без удалённой
авторизации и без публикации в интернете. Из другого компьютера этот URL не доступен.

## Подключения через интерфейс

Для поискового пилота заполните Yandex API key, Folder ID, OpenRouter API key и
идентификатор модели OpenRouter. Конкретная модель не выбрана за агентство.
Сохранение не вызывает платные сервисы; вызовы выполняются по кнопке поиска.
Пустые поля при повторном сохранении оставляют ключи без изменений.
Сайт не возвращает сохранённые ключи в браузер. Файл `.env` сохраняется с правами 0600.
Название модели лежит в `config/models.yaml`. Подмена ключа окружением процесса
не перекрывает значение, сохранённое через сайт.

Для Yandex нужны роль `search-api.webSearch.user` и scope `yc.search-api.execute`.
[Официальная инструкция](https://aistudio.yandex.ru/en/docs/search-api/operations/web-search-sync).
Сохранённый ключ ещё не означает проверенную доступность/оплаченный баланс.
Первый боевой прогон после ввода ключей остаётся обязательной интеграционной проверкой.

Поиск работает в фоне: интерфейс получает ID задания и показывает сохранённый прогресс.
Можно закрыть вкладку; само приложение должно оставаться запущенным. По кнопке
«Остановить» отмена происходит после текущего сетевого запроса. Уже сохранённые
карточки остаются. После перезапуска активное задание отмечается прерванным, оно
не расходует деньги автоматически повторно; можно явно нажать «Повторить».
Очередь и история сохраняются в SQLite; запускается один рабочий процесс.

На экране есть «Попробовать без ключей»: три вымышленные публикации проходят тот же
конвейер, дают две карточки разных корпусов. HTTP и модель в этом режиме заменены
локальными примерами. Учебные результаты попадают только в демо-набор.

Настройки объёма — `config/discovery.yaml`: 3 запроса на регион (12 для четырёх
приоритетных регионов), до 20 страниц, до 8 модельных групп по 24 000 символов.
Результаты разных запросов чередуются, чтобы первые страницы одной географии не
вытеснили остальные. Это ограниченный обзор, а не исчерпывающий мониторинг страны.
Пропущенные из-за лимита страницы и ошибки показываются в результате.

Загрузчик получает только публичный HTTP(S), HTML/обычный текст. Проверяет IP до
соединения и повторно для перенаправлений, соединяется с проверенным адресом.
Не использует cookies, авторизацию, системный proxy или браузерный JavaScript.
Лимиты: 2 МБ ответа, 40 000 символов сохранённого текста; модель может получить ещё
более короткий фрагмент по лимиту группы. PDF-источники, JS-страницы, авторизация и
неподдерживаемые кодировки/типы ответа пока не обрабатываются полноценно.

Сохраняются очищенный текст, ссылка, хеш исходного ответа, дата загрузки и дата
публикации из метатегов, если она найдена. Исходный HTML целиком не сохраняется.
Недоступная страница даёт явно помеченный поисковый фрагмент. Ошибка одного источника
не останавливает остальные; если не выполнен ни один поиск или ни одна модельная
группа, задание завершается ошибкой, сохранив уже полученные документы.

Модель извлекает название, корпус, вид события, цитату, темы и необязательную дату.
Код проверяет дословную цитату, название, указание корпуса и наличие даты в цитате.
Будущая дата не записывается как уже произошедшее событие. Дата публикации отдельно
от даты события. Смысл всех утверждений вторым проверяющим пока не верифицируется.

Карточки объединяются только в наборе результатов поиска: нормализованное название,
регион с опорой на текст и корпус. Неизвестный регион не объединяется между разными
URL; неизвестный корпус не сливается с конкретным. Это консервативное объединение,
не покорпусный реестр ЕИСЖС. Материалы Excel автоматически с веб-карточками не склеиваются.

Успешные поисковые шаги и прочитанные страницы кешируются на день UTC; недоступные
страницы пробуются заново при следующем запуске. Модель кешируется по содержимому
и конфигурации. Повторные цитаты с того же URL не создают новые события из-за изменения
рекламы в HTML. Неудачный оплаченный запрос может не попасть в кеш; его повтор может
потребовать нового платного вызова. Общий денежный лимит задавайте на ключе провайдера:
внутренний финансовый учёт ещё не реализован.

## Чаты и уточнения

В карточке: «Добавить выгрузку чата». Формат JSON скачивается там же. Требуется
`access: public`, ISO-время с часовым поясом, автор и ID сообщения. Лимит 10 МБ в UI,
до 10 тысяч сообщений. Имена из метаданных, контакты и номера квартир удаляются,
ID авторов заменяются HMAC с локальной солью. Произвольные чужие имена в тексте,
если их нет в метаданных, могут остаться: это базовая очистка, не гарантия обезличивания.
В UI/PDF выводятся агрегаты, не тексты сообщений и не имена участников.

Темы и тональность берутся из полей выгрузки. Неразмеченное сообщение не считается
нейтральным. Доля негатива считается только среди размеченных; это не доля конфликта.
Окно сводки — 30 дней. Тексты старше 180 дней очищаются при обращении к сводке;
постоянный фоновый механизм удаления ещё не установлен.

Повторные сообщения не добавляются. Импорт чата меняет темы для выбора дополнительных
услуг и новую версию PDF. Для неподтверждённых объектов первым предложением остаётся
диагностика. Все 12 офферов — черновики для вычитки агентством.

## PDF и данные

PDF — две A4: «Что происходит» и «С чем идти». Встроен кириллический шрифт,
кликабельные источники, версия и дата, сведения чатов и уточнение аналитика.
При нехватке данных отсутствующие оценки/даты обозначаются явно. Это сокращённая
реализация структуры ТЗ: есть хронология утверждений из публикаций; ещё нет сверки с покорпусным реестром, графика за 8 недель,
сопоставленного кейса и второго модельного ревью. Их содержание не выдумывается.

Один снимок данных создаёт одну версию; изменение содержания — новую. Вёрстка
проверяет вместимость и не обрезает текст. Очень длинные уточнения могут потребовать
сокращения. PDF-выгрузка не отправляется девелоперу автоматически.

Рабочая SQLite: `data/local/workspace.sqlite3`. Исходники: `data/intake/`.
Ключи, данные и Telegram-сессии исключены из Git. SQLite независима от будущей
PostgreSQL: автоматического переноса между этими базами пока нет.

```sh
uv run radar backup
```

Команда создаёт согласованную копию SQLite в `data/backups/` без ключей. Оригиналы
Excel и `.env` нужно хранить отдельно. Для восстановления остановить приложение,
сохранить текущую папку `data/local`, положить копию как `workspace.sqlite3` в новую
папку `data/local`, затем запустить. Не оставлять старые WAL/SHM-файлы рядом с копией.
